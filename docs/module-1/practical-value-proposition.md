# Practical activity: Value proposition canvas

Create the first Portfolio of Evidence artefact for your selected organisation or case.

## Task

Prepare a two-page value proposition canvas containing:

1. Customer profile — jobs, problems, desired gains and decision constraints.
2. Offer profile — products or services, problem relievers, gain creators and proof.
3. Alternative analysis — at least three alternatives, including doing nothing where relevant.
4. Draft value proposition — one concise internal positioning statement.
5. Evidence notes — identify which claims come from research and which remain assumptions.

## Minimum evidence standard

- At least three credible sources or direct customer observations.
- Clear separation between evidence and assumptions.
- One revision after feedback or self-review.
- Editable source file and final PDF.

## PoE artefact

Submit as **Artefact 1: Customer value and value proposition canvas**.
