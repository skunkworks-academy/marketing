# Practical activity: Segment profile

Create a segment-selection matrix and one evidence-based target persona.

## Deliverables

1. Define at least three candidate segments.
2. Score each segment against five or more attractiveness criteria.
3. Weight criteria where some factors matter more than others.
4. Select one priority target and justify exclusions.
5. Create one decision-useful persona for the selected segment.
6. Record assumptions requiring later validation.

## PoE artefact

Submit as **Artefact 3: Segmentation, targeting and persona pack**.

## Quality criteria

- Segments differ in ways that affect marketing decisions.
- Scoring is explained rather than arbitrary.
- The persona is based on evidence.
- The recommendation reflects capability and risk.
