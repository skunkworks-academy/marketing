# Portfolio submission checklist

Confirm the following before submission:

- [ ] All eight required artefacts are present.
- [ ] The evidence index maps every artefact to outcomes and rubric criteria.
- [ ] Final PDFs and editable source files are included.
- [ ] Research sources and dates are recorded.
- [ ] Assumptions are separated from verified findings.
- [ ] Confidential and personal information is protected.
- [ ] AI and other assistance is declared.
- [ ] File names follow the course convention.
- [ ] Revisions and feedback responses are visible.
- [ ] The authenticity declaration is completed.
- [ ] The final integrated report is internally consistent.
- [ ] Every material claim can be substantiated.
