# Evidence requirements

Each artefact should contain enough context for an independent assessor to understand what was done, why it was done and how the evidence supports the decision.

## Evidence index fields

| Field | Description |
|---|---|
| Artefact ID | Unique identifier |
| Outcome or criterion | Requirement demonstrated |
| File name | Exact submitted file |
| Evidence description | What the assessor should examine |
| Source or origin | Research, workplace activity, simulation or prior evidence |
| Date and version | Currency and revision history |
| Learner contribution | Work completed or directed by the learner |
| Confidentiality status | Public, internal, confidential or redacted |

## Acceptable evidence

Evidence may include research notes, interview guides, analysis tables, spreadsheets, diagrams, drafts, feedback, revised versions, plans, presentations, reports, screenshots, analytics extracts and professional-discussion records.

## Prior learning

Relevant prior evidence may be considered where it is valid, authentic, current and sufficient. The assessor may request mapping, updated context or a professional discussion. Recognition of prior learning is an assessment process, not an automatic exemption.

## Confidential information

Redact personal or commercially sensitive details where possible. Where redaction weakens verification, arrange controlled assessor access rather than publishing confidential information.
